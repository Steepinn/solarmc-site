# Жители

К обычным профессиям добавлены новые рабочие места. Поставь блок-станцию, житель без профессии займёт её и откроет свои сделки.

## Профессии

| Станция | Житель | Из чего |
|---------|--------|---------|
| Садовый стол | флорист | 2 цветка + доски |
| Охотничий пост | охотник | кожа + стрела + брёвна |
| Шахтёрский стол | шахтёр | железная кирка + сырое железо + камень |
| Стол океанографии | океанограф | бумага + нить + бочка |
| Лесной верстак | лесник | листва + доски + брёвна |
| Чертёжный стол | инженер | бумага + синий краситель + доски |
| Алтарь пурпура | эндер-учёный | пурпур + эндерняк |
| Верстак порчи | незер-учёный | незерский кирпич + искажённые и багровые доски |
| Холодильник | ледяной | ель + лёд, плотный лёд и синий лёд |
| Позолоченная станция | вознёсшийся | дубовое бревно + золотые блоки |

{% hint style="warning" %}
Позолоченная станция в предмете помечена как незавершённая. Сделки могут быть пустыми или меняться.
{% endhint %}

## Как завести

1. Найди деревню или приведи жителя (лодка / вагонетка)
2. Скрафти станцию и поставь рядом
3. Дождись, пока безработный её займёт
4. Торгуй как обычно — изумруды и уровень профессии

Ванильные библиотекарь, фермер, оружейник и остальные никуда не делись.
