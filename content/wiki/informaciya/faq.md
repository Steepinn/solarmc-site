# Частые вопросы

### Какая версия?

**Minecraft Java 1.21.1** + Fabric и [клиентская сборка](/docs/mods/client-mods).

### Можно с телефона / Bedrock?

Нет. Только Java на ПК.

### Нужна лицензия?

Сервер с `online-mode=false`: можно зайти по паролю. Лицензия удобнее для скина и безопасности аккаунта.

### Как получить проходку?

[Заявка на сайте](/applications) + членство в [Discord](https://discord.gg/DjmJzUARCy).

### Где карта мира?

[/map](/map) (BlueMap). С SONNE можно скрываться с карты: `/hide` / `/show`.

### Скиллы и происхождение?

* Скиллы (Puffish) — **`K`** ([гайд](/docs/mods/levelz)).
* Перераспределить очки — **Сфера перепрокачки** из [магазина](/shop): сбрасывает все четыре дерева и возвращает очки.
* Origin выбираешь при входе; повторный выбор у игроков закрыт. Смена — товар [Перерождение](/shop).

### Как смотреть рецепты кухни?

Команда **`/fdguide`** (или **`/fdbook`**) — меню блюд и станций. Также книга внутри кастрюли. Подробнее: [кухня](/docs/mods/farmers-delight).

### Какие команды есть у всех?

Смотри [Полезные команды](/docs/server-content/poleznye-komandy-dlya-igrokov) и `/cd` в игре.

### Есть ли /home, /tpa, полёт за донат?

**Нет.** Донат Season 3 — без P2W-мобильности. Подробности: [Привилегии](/docs/informaciya/donat).

### Что даёт SONNE / SONNE+?

Коротко: hat, верстак, питомцы, maphide, промокод, без КД чата/скина. **Без** `/nick` и `/ec`. Полный список — в [донате](/docs/informaciya/donat) и на [/shop](/shop).

### Как привязать Discord к нику?

В игре **`/dslink`**, код отправь боту в ЛС. После этого профиль на сайте подтянет MC-ник и достижения.

### Где мои достижения?

На сайте: **Профиль** → блок «Достижения» (коллекция с сервера).

### Куда писать, если баг / гриф?

* Баг / доступ: [техподдержка](/support)
* Гриф / читы: `/report` или тикет «Жалоба»
* Вопрос модерам: `/ask`

### Это ванилла?

Почти: ванильный геймплей + расы, скиллы, сезоны, кухня с аддонами, [виноградник](/docs/mods/vinery), рыбалка, [звери](/docs/mods/zveri) (Faunus + утки), данжи, боссы, [артефакты](/docs/mods/artefakty), [эндерит](/docs/mods/enderit), [почта](/docs/mods/pochta), [банкомат](/docs/mods/dengi), [рации](/docs/mods/radio), [пинг](/docs/mods/ping). Vanilla-прогресс (алмазы, Энд) никуда не делся.

### Как говорить на расстоянии / ткнуть точку?

* Рядом — **`V`** ([голос](/docs/server-content/nastroika-golosovogo-chata))
* Дальше — [рация](/docs/mods/radio) на одной частоте
* «Сюда смотри» — [пинг](/docs/mods/ping), часто Mouse5 или `/pingwheel config`
* Свой отряд меток — `/metka create название пароль`, гайд на той же странице
* Стулья и столы — [мебель](/docs/mods/mebel); новые профессии деревни — [жители](/docs/mods/zhiteli)
