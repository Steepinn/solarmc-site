# Полезные команды

Актуально для **Season 3**. В игре также есть меню **`/cd`** / **`/команды`**.

## Для всех игроков

### Общение и модерация

| Команда | Что делает |
|---------|------------|
| `/ask …` | Вопрос модераторам |
| `/report ник …` | Жалоба на игрока |
| `/msg ник …` / ответ | Личные сообщения |
| `/ignore ник` | Игнор в чате |
| `/me …` | Emote в чат |
| `/list` | Кто онлайн |
| `/help` | Справка |

### Экономика и инфо

| Команда | Что делает |
|---------|------------|
| `/balance` / `/bal` | Баланс ячейки |
| `/pay ник сумма` | Перевод |
| `/baltop` / `/moneytop` | Топ богачей |

Банкомат, обмен руды и PIN ячейки — [деньги](/docs/mods/dengi).
| `/afk` | АФК (не кикает) |
| `/getpos` | Координаты |
| `/realname` | Настоящий ник под ником |
| `/mail` | Почта |

### Удобства тела (GSit)

| Команда | Что делает |
|---------|------------|
| `/sit` | Сесть |
| `/lay` | Лечь |
| `/crawl` | Ползти |
| `/spin` | Крутиться |

(Также можно сесть ПКМ на стул/ступеньку, если разрешено.)

### Прочее

| Команда | Что делает |
|---------|------------|
| `/skin` | Скин (у обычных — с кулдауном) |
| `/voicechat` | Настройки голоса |
| `/pingwheel config` | Настройки пинга по миру |
| `/metka` | Группа меток: create / join / leave / info |
| `/fdguide` / `/fdbook` | Меню рецептов кухни (Farmers Delight) |
| `/cr book` | Книга кастомных крафтов |
| `/co i` / inspect | История блока (CoreProtect inspect) |
| `/dslink` | Привязка Discord ↔ Minecraft |
| `/origin` | Меню Origin (обычно недоступно после выбора) |

### Клавиши

* **`K`** — скиллы (Puffish)
* **`G`** — активная способность Origin (у многих рас)
* **`V`** — голосовой чат (по умолчанию)
* **Mouse5** (часто) — пинг по миру; иначе `/pingwheel config`
* Рации — [гайд](/docs/mods/radio)

## SONNE

Всё из списка выше **плюс**:

| Команда / фича | Описание |
|----------------|----------|
| `/hat` | Блок на голову |
| `/workbench` / `/wb` | Верстак |
| `/pet` / `/pets` | **1** пассивный питомец, цвет имени |
| `/hide` `/show` | Скрыть/показать себя на BlueMap |
| Промокод | Создать личный реферальный код |
| Чат | Без кулдауна сообщений |
| `/skin` | Без кулдауна |

**Нет** у доната: `/nick`, `/ec`, fly, kits, homes, tpa.

Подробнее: [Привилегии](/docs/informaciya/donat).

---

## SONNE+

Всё из **SONNE** плюс:

* **1** питомец **любых** типов (не два);
* питомец на голове (косметика);
* HEX-цвет имени питомца.

По-прежнему **нет** полёта/езды на питомце, `/nick`/`/ec` и P2W.

---

## Чего нет у игроков (важно)

Намеренно отключено для баланса сезона:

* `/home`, `/sethome`, `/tpa`, `/tpahere`
* `/warp`, `/spawn` (как у донатеров)
* `/fly`, `/heal`, `/feed`, `/god`
* киты (`/kit`) за донат

Staff-команды — только у хелперов/модеров/админов (см. [вики для администрации](/docs/admin/home)).
