# Модерация

## Цели

* Честный PvE Season 3: без читов, дюпов, грифа, токсика.
* Доказательства: скрины, `/co`, репорты, тикеты.
* Наказания по [правилам](/docs/informaciya/rules), без самодеятельности.

## Каналы

| Канал | Зачем |
|-------|--------|
| [/admin](/admin) → Заявки | проходка |
| [/admin](/admin) / [/support](/support) | тикеты |
| Discord staff | эскалация |
| `/ask` `/report` | сигналы в игре |
| CoreProtect | гриф |

На сайте staff **не** получает пуш «новый тикет/заявка» в колокольчик — смотри админку и Discord.

## Заявки на проходку

1. Анкета: возраст, опыт, адекватность, совпадение Discord.
2. Одобри / отклони с причиной.
3. Одобрение → роль проходки Discord (Player на сайте).

Мультиаккаунты и троллинг — отказ.

## Тикеты

* Ответ по делу.
* Гриф → координаты / время / ники → `/co lookup`.
* Закрой тикет после решения (игроку уйдёт уведомление).

## Наказания

Ориентир — таблица в правилах (Mute / Wortex / Ban / Hardban).

* Чат / мат из списка — мут по регламенту.  
* Гриф / дюп / читы — бан + доказательства в тикете.  
* RMT — hardban по правилам.

## Донат и исключения

* Не выдавай sonne «в долг» без оплаты/согласования admin.
* Не возвращай nick/ec/fly/homes/kits на донат.
* Споры по оплате — эскалация admin + тикет.

## Конфликт интересов

Не модерируй баны/тикеты по своим альтам и близким — передай другому staff.

## Блок на сайте

В профиле `/u/…` админ видит **Заблокировать**.  
Блок сайта ≠ игровой бан. Для сервера отдельно `/ban` / LP.
