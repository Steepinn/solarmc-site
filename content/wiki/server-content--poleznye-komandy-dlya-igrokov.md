# Полезные команды для игроков

<figure><img src="/files/Gwa2iGPiJeAbjql6MC83" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
Пользовательские команды будут дополнятся по мере появления!
{% endhint %}

&#x20;<mark style="color:$danger;">`/ask <вопрос>`</mark> - возможность спросить администраторов и модераторов, любой вопрос!\
&#x20;<mark style="color:$info;">`/afk`</mark> - включить режим АФК! (что бы вас не кикало)\
&#x20;<mark style="color:$info;">`/cr book`</mark> - узнать все кастомные крафты на сервере!\
&#x20;<mark style="color:$info;">`/co inspect`</mark> - проверка всех действий по выборному блоку/сундуку!\
&#x20;<mark style="color:$primary;">`/crawl`</mark> - ползти!\
&#x20;<mark style="color:purple;">`/cd команды`</mark> - [гайд тут](https://mcsolar.gitbook.io/solar/~/revisions/36r7VsSlcVYSURvfAMLH/server-content/kastomnye-plastinki)!\
&#x20;<mark style="color:$primary;">`/lay`</mark> - лечь на землю!\
&#x20;<mark style="color:$primary;">`/msg`</mark> - личное сообщение любому игроку!\
&#x20;<mark style="color:$info;">`/playtime или /playtime <ник>`</mark> - позволяет узнать наигранные часы на сервере! (афк не считается)\
&#x20;<mark style="color:$danger;">`/report <ник> <причина>`</mark>- жалоба на игрока внутри игры!\
&#x20;<mark style="color:$primary;">`/sit`</mark> -  сидеть!\
&#x20;<mark style="color:$primary;">`/skin`</mark> - настройка скина!\
&#x20;<mark style="color:$info;">`/spdrug book`</mark> - получение книги рецептов для наркоты!\
&#x20;<mark style="color:$primary;">`/spin`</mark> - начать крутится!\
&#x20;<mark style="color:blue;">`/voicechat`</mark> - настройка войс чата!\
&#x20;<mark style="color:blue;">`/hat`</mark> - одеть блок на голову! (для pulse подписки)\
&#x20;<mark style="color:blue;">`/moneytop`</mark> - узнать список самых богатых людей на сервере!
