# Как начать играть

От Discord до первого дня на сервере.

## 1. Discord

Зайди на [Discord Solar](https://discord.gg/DjmJzUARCy). Без Discord проходку не выдают.

## 2. Заявка

1. Войди на [сайт](/) через Discord
2. Открой [Заявки](/applications) и заполни форму
3. Дождись решения (обычно в течение суток). Статус — в [профиле](/profile)

После одобрения можно заходить на сервер.

## 3. Клиент и лаунчер

Нужен Minecraft Java **1.21.1** и сборка сервера.

1. Открой [Лаунчер](/launcher)
2. Выбери:
   * **Официальный Minecraft** — если лицензия
   * **TLauncher** — если TLauncher
3. Не мешай эти две сборки

**На Solar вход только через лаунчер** — он подставляет подключение сам. Ручной ввод в «Сетевая игра» не используется.

Подробнее: [клиент](/docs/mods/client-mods).

## 4. Первый вход

При первом входе:

1. **Пароль** — сохрани
2. **Раса** — на весь сезон; смена потом — [Перерождение](/shop)
3. По желанию **`/dslink`** — привязка Discord к нику

## 5. Первые часы

1. Команды: **`/cd`**
2. Скиллы — **`K`**
3. [Квесты](/docs/mods/questlog) — глава «Добро пожаловать»
4. Голос — **`V`**
5. Не лети сразу к боссам: обустройся, прокачайся, глянь [карту](/map)
