# Solar Launcher builds

Положи сюда файлы (имена как в `src/config/launcher.ts`):

- `solar-launcher-official.zip` — для официального Minecraft Launcher
- `solar-launcher-tlauncher.zip` — для TLauncher

Либо задай внешние ссылки в `.env.local`:

```
NEXT_PUBLIC_LAUNCHER_OFFICIAL_URL=https://...
NEXT_PUBLIC_LAUNCHER_TLAUNCHER_URL=https://...
```
