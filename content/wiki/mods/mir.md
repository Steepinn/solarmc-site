# Мир вокруг

Ванильные блоки умеют чуть больше. Отдельных новых верстаков нет — ставишь то же, что в ванили, кликаешь иначе.

## Котёл

Крафт котла — как в ванили: 7 железных слитков буквой U.

Что можно:

* **ПКМ** предметом по котлу — крафт/покраска «в руках»
* Кинуть предмет в котёл — тот же крафт «в мире»
* Краситель в воду — вода красится, можно мешать цвета
* Зелья в котле <mark style="color:$primary;">смешиваются</mark> (до 8 эффектов). Противоположные гасятся (скорость ↔ медлительность и т.п.)
* Котёл стыкуется с забором

Слой воды/лавы тратится. Не пей смесь, если не помнишь, что лил.

## Декор — как поставить

| Что | Как |
|-----|-----|
| Вещь на подвесной табличке | ПКМ предметом по табличке |
| Инструмент на крюке | ПКМ инструментом по натяжному крюку |
| Ковёр на ступеньке / плите | ПКМ ковром по блоку |
| Двойной торт | торт на торт |
| Головы стопкой | голова на голову |
| Свечи на черепе | ПКМ свечой |
| Горшок на потолок | ПКМ горшком по нижней грани |
| Фонарь на стену | ПКМ фонарём по стене (не только снизу) |
| Флаг на потолок | ПКМ флагом по нижней грани |
| Блок на кувшинке | ПКМ любым блоком по кувшинке |
| Колокол по цепи | ПКМ по цепи, если она ведёт к колоколу (до 16 звеньев) |

{% hint style="danger" %}
Фонарь без опоры падает. С большой высоты бьётся и может зажечь огонь.
{% endhint %}

## Мелочи боя

* Снежок ненадолго замораживает
* Огненный заряд можно кинуть (есть гравитация); раздатчик стреляет тем же зарядом
* Факел в руке поджигает, кого ударил (~2 сек)

Кафедра: книга редактируется удобнее.

## Тропы

Где часто ходят **игроки**, земля меняется сама (мобы не топчут):

трава → земля → тропинка → гравий → камень → каменный кирпич

Медленно. Дорожка к дому появится сама; всю равнину за вечер не укатаешь.

## Дикая природа (Good Ending)

Болота и берёзовые леса выглядят иначе: больше воды, высокие берёзы, лианы/свисающая листва, болотные биомы вроде **Marshy Swamp** и леса **Oak Hammock**.

* Ночью на болотах — <mark style="color:$success;">светлячки</mark>. Банка + ПКМ по рою → банка со светлячками → из неё крафтится мирный фонарь
* В лесах встречаются дятлы и прочий ванильный вайб-моб
* Цветы и растительность гуще — для баз и декора удобнее

Это про атмосферу и лут «на месте», не про новые данжи. Новых зверей для приручения ищи в [зверях](/docs/mods/zveri).
