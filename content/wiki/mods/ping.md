# Пинг по карте

Можно ткнуть точку в мире — союзники увидят метку (Ping Wheel). Удобно в данже, на корабле или при стройке.

## Как пользоваться

1. Смотри туда, куда хочешь ткнуть
2. Жми клавишу пинга — по умолчанию часто <mark style="color:$primary;">Mouse5</mark> (боковая кнопка мыши)
3. Метка появляется у всех рядом по правилам мода

{% hint style="warning" %}
Если Mouse5 нет — открой настройки: команда <mark style="color:$info;">`/pingwheel config`</mark> или Настройки → Управление → Ping Wheel, повесь пинг на удобную клавишу.
{% endhint %}

## Зачем

* «Сюда сундук / босс / выход»
* Не писать координаты в чат каждую минуту
* На корабле — куда смотреть рулевому

С голосовым чатом (**`V`**) и [рациями](/docs/mods/radio) пинг закрывает «куда смотреть», а голос — «что делать».

## Группы меток

Метки можно ограничить своим отрядом. Команды:

| Команда | Что делает |
|---------|------------|
| `/metka create название пароль` | создать группу |
| `/metka join название пароль` | войти |
| `/metka leave` | выйти |
| `/metka info` | твоя группа |
| `/metka members` | кто внутри |
| `/metka settings …` | пароль, описание, открытый вход, кик — у создателя |

Алиасы: `/pinggr`, `/pinggroup`. Справка: `/metka help`.

Пока ты в группе, метки видит отряд, а не весь сервер.
