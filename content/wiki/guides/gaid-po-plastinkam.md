# Пластинки со своей музыкой

Можно сделать пластинку со своей песней и поставить её в мире.

## Самый простой способ

Держи пластинку в руке и напиши:

`/cd create remote "ссылка на песню" "название"`

Готово — пластинка с музыкой у тебя в руках.

## Если песня лежит файлом (mp3)

1. Залей mp3 на Google Диск и открой доступ «всем по ссылке».
2. Сделай из ссылки прямую ссылку на скачивание (конвертер вроде [gddl](https://lonedev6.github.io/gddl/)).
3. В игре скачай файл:
   `/cd download "прямая_ссылка" название.mp3`
4. Создай пластинку:
   `/cd create local "название.mp3" "Как назвать диск"`

{% hint style="warning" %}
Кавычки в команде важны — без них команда часто ломается.
{% endhint %}

## Чтобы слышать музыку

Нужен голосовой чат из сборки (клавиша **V**). Без него пластинка может не играть для тебя.

Если что-то не выходит — спроси в Discord или через `/ask`.
