## Как обновляется вики

Состав сверяется при запуске разработки и сборке сайта. Для постоянного наблюдения за папками используйте `npm run sync:wiki:watch`; разовая синхронизация — `npm run sync:wiki`. Если сервер недоступен, сохраняется предыдущий снимок. На удалённом хостинге нужен доступ к папкам сервера либо перенос нового снимка вместе с сайтом.

Автоматический каталог не заменяет проверку игровых механик: описания и инструкции поддерживаются отдельными статьями.
