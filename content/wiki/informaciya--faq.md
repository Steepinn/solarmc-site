### Какая версия сервера?

Сервер работает на новейшей версии `1.21.11` .

Сервер будет обновляться на новые версии по мере их готовности к комфортной игре.

### Можно ли зайти с телефона/приставки/консоли?

Нет. Сервер поддерживает только Java Edition, которая официально доступна только для компьютеров.

### Необходима ли лицензия?

Использовать лицензию необязательно - сервер доступен с пиратских аккаунтов.

Но используя лицензию вы получите лицензионную авторизацию на сервер без паролей.

### Какая валюта сервера?

На сервере используется уникальная система ванильной экономики. Узнать больше, можно только играя на сервере!

### Когда откроется сервер?

Сам сервер Solar существует не так долго, начиная с 29 февраля 2025 года!

### Когда закончится 2 сезон?

Точного ответа дать нельзя, ведь сезон длится в зависимости от интереса игроков. Пока сезон интересен игрокам — он будет жить. Тем не менее, один сезон будет длится примерно 4 месяца.
